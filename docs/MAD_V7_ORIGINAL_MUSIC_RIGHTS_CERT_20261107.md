## V7 resolution — rights-first original-author admission
1. Retain existing Openverse metadata searches, then **always** search the existing Wikimedia Commons provider for the first-party original recordings by Purrple Cat. This is a curated, discovered and LIVE source-checked artist pool, NOT automatic license approval merely because a search result says CC BY. One bounded Commons metadata search + two Openverse queries max, eight model-visible candidates. AI chooses by exact ID from the shortlist; invalid IDs fall back deterministically, without inventing a song or bypassing copyright checks.
2. Each original Commons file must independently return in the LIVE MediaWiki canonical API: audio media type; exact original title, media URL and source filename; accepted CC BY 2–4, CC0 or PDM license URL matching the search lead; **no** copyright dispute or pending license review category; **positive** `Category:Self-published work`; original work credit; and artist credit matching the actual Commons uploading account. Known AI-generated/synthetic composition claims and explicit noncommercial/no-derivative restrictions fail closed. Metadata omissions, ambiguous source, mismatched media/author or incomplete category pagination fail closed.
3. Existing polite sequential ranged importer preserves HTTP 206 Content-Range/length validation, original MediaWiki SHA1, private SHA256, max 16 MiB and no arbitrary hosts or CDN-bypass. Audio is independently probed and duration must cover the edit. No audio is cached in a public repository.
4. Existing renderer's internal rights enum remains `CC BY` / `CC0` / `PDM` for compatibility, while the signed rights receipt records the actual license version (e.g., `CC BY 4.0`), title, composer/performer/uploader, original file page, license link, source SHA and private byte hash. Attribution text includes **adapted excerpt, mixed and mastered for short-form video**. An AI-picked lead that cannot pass rights checks cannot be mixed; the final receipt distinguishes original AI pick from a rights-safe fallback with `discovery.actual_selected` and `actual_selection_method`.
5. Owner creative brief still drives Groq sound selection, with txtai RAG context; V7 Gemini/Groq, FFmpeg, signed OIDC claim, private KV + D1, 30-minute delivery, owner code and no-publication gates are unchanged. No legacy V1–V6 workflows reactivated.
