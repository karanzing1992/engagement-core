# Ashwakaal — Support Channels

Registered as a separate workstream in the Moksha Master technology registry on 11 October 2026.

Status: channel identities, connected apps, integrations and source repository have not yet been verified. Registration does not mean any channel is active.

Scope: owner-verified support inboxes, community channels, platform connections, messaging and publishing interfaces, incident handling, and audit/analytics capabilities. Keep Ashwakaal records and permissions strictly separate from other brands.

Channel register: for each verified platform, record the official handle and URL, channel purpose, authorized account owner, approved read/write scopes, API integration, evidence, last verification date and test status. Do not fabricate a channel or infer live publishing from source code.

Report verified channel changes through the shared Supabase change-event inbox when no monitored GitHub repository exists. Do not add an unverified repository to the independent Google Apps Script list. If a verified Ashwakaal repository becomes available, explicitly authorize and test its onboarding to the worker.
