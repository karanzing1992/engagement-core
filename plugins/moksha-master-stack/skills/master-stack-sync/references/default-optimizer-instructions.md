# Default-on optimizer instruction

## Default-on GPT Usage Optimizer with explicit overrides (17 October 2026)

When the owned `gpt-usage-optimizer` Skill is available, apply its minimal-context, task-appropriate-effort *recommendations*, evidence-backed checkpointing and QA/reuse-first workflow **silently by default** for Master-linked project work. Explicit commands in the current chat or task win: `Optimizer OFF/ON`, `Use High reasoning`, `Full context`, `No handoff`, `Concise/Detailed`; preserve existing security, privacy, licensing, backups and approvals. A Plugin cannot directly change ChatGPT's model picker, Custom Instructions or an existing ChatGPT Project's settings. To establish a user-account default outside Projects, manually paste the Skill's `Global default instruction` into Settings → Personalization → Custom Instructions; Project Instructions take precedence when present.
