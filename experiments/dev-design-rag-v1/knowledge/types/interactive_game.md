# Interactive Game and 3D Interface UX — Type Graph

Sources: https://www.w3.org/TR/wcag/ ; https://developer.apple.com/design/human-interface-guidelines/ ; https://developer.android.com/design/ui/mobile/guides/foundations/accessibility

## Game HUD and legibility
Keep HUD, instructions and feedback readable while gameplay continues, scale UI across camera sizes and distinguish gameplay action from UI menus. Use consistent control feedback, legible visual affordances and clear pause/exit options.

## Input and interactions
Support expected native keyboard/gamepad/touch paths, focus and screen reader as compatible with the engine. Preserve control state through menus and provide recovery from input mistakes. Ensure UI remains legible over varied 3D backgrounds using contrast backplates.

## Visual artistry
Create an internally consistent visual language for character, environment and interface; avoid copied non-open references. Evaluate motion quality, frame stability, visual clarity and aesthetic originality independently. Do not mistake static screenshot quality for gameplay quality.

## Acceptance
Use actual interactive functional QA and asset licensing checks, independent artistic score >=95 on scoped gameplay/UI evidence, no unreviewed production release.
