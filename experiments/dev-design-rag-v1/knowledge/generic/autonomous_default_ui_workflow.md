# DEFAULT UI/UX AUTONOMOUS DESIGN WORKFLOW — OWNER DIRECTIVE, 10 NOV 2026

This is a global design-process policy, brand-neutral; keep brand and project facts in their own isolated RAG layers.

All website/UI/UX/redesign/visual design requests must route through the existing DEV DESIGN RAG 1.0 and its authorized autonomous Matrix Dev Brain engine by default. Do not substitute an assistant's direct/manual coding for an autonomous engine execution or call it engine-certified. The mandatory order is:

1. Retrieve verified generic, project-type, brand and project-specific RAG in isolation.
2. Autonomous engine produces concepts and an implementation design; owner-supplied assets, claims and media provenance are locked.
3. Autonomous engine implements the actual site/app in a staging workspace, using open-source/free first.
4. Render the actual build at representative desktop/mobile breakpoints; capture real screenshots for review.
5. Independent artistic reviewer critiques those rendered screenshots and checks project-specific design originality, typography, color, imagery, trust and composition; reject below 95/100. No invented score.
6. Technical QA: Playwright functional journeys, axe/WCAG, Lighthouse mobile/desktop, keyboard, broken links, image loads and responsive layout; fix and re-review as needed.
7. Deploy only to an isolated noindex review URL and verify live behaviour.
8. Production release requires owner approval and the established security/release gates.

A manual prototype or emergency fix is allowed only on explicit owner exception and remains labeled MANUAL / NOT_AUTONOMOUS / NOT_ARTISTICALLY_CERTIFIED. A failure in any step is recorded, not bypassed. Independent review may use an approved alternate model when a free model times out. Never let generic RAG ingest a particular brand's private assets or material. Preserve rollback and existing deployments.

Policy machine record: runtime/autonomous_ui_workflow.json. Evidence gate: runtime/verify_autonomous_ui_flow.py. This is a default workflow contract for Dell’s design path, not an assertion that every external application automatically invokes this guard.
