# Step Into Moksha — source-only interactive tour scaffold

Private working prototype package contains seven short user-supplied guest-video clips; none are included in this public GitHub repository. Refer to the internal Phase 1 rollout and issue #310.

This directory hosts the portable interaction scaffold only. To test with authorized local clips, place consent-cleared MP4s under `media/{arrival,space,sauna,cold,water,earth,afterglow}.mp4`. Run a local static web server and open `index.html`. Missing video renders an explicit placeholder. Do not deploy or publish without guest media and brand gates.

The official real Moksha brand image is referenced unchanged from the existing repository asset, not AI generated.

No trackers, AI model, keys, CRM calls, pricing, external booking or chargeable services are used. Source-only; production website unchanged. Later handoffs must be modular and separately authorized for `moksha_wordpress`.
