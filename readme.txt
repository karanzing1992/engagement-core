Admin-only video editorial draft workspace. Does NOT post or schedule social content.

== Description ==
Private job records, source/license ledgers, verified logo attachment selection,
access-controlled GitHub artifact links for unreleased preview videos,
creative policy validation, administrator-only REST API and review-state controls.
Rendering should happen on a separate, secured cloud worker, not the WordPress host.

== Installation ==
1. Upload this ZIP using WordPress Admin > Plugins > Add New > Upload Plugin.
2. Review the code and activate the plugin.
3. Open Media Studio from the admin sidebar.

No changes to any existing plugin, theme, page, WooCommerce checkout, or publishing workflow.
